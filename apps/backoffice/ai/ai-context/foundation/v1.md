# Module: Foundation & Theme (FE-SH-00-01 & FE-SH-00-02)

## Module Overview

This module provides the core design system foundation, Mantine v8 theme configuration, root responsive AppShell layout, and reusable UI components for the She Bloom backoffice web application. It acts as the shared UI baseline for all future backoffice operational modules (Admin, Moderator, Mentor).

---

## Module Responsibilities

* Configure the centralized Mantine v8 theme (`src/theme.ts`) including brand color palettes, typography, responsive breakpoints, and component defaults.
* Provide Google Fonts integration for body (`Outfit`, `DM Sans`) and headings (`Playfair Display`).
* Provide the root application shell (`AppLayout.tsx`) utilizing Mantine's `alt` layout, deep violet sidebar styling, and responsive drawer navigation.
* Provide standard, reusable design system components in `src/components/` (`PageHeader`, `StatusBadge`, `DataTable`, `StatCard`, `FilterChipGroup`, `StatePlaceholder`).
* Standardize responsive behaviors across desktop, tablet, and mobile viewports (e.g., table-to-card transformation and tablet column hiding).

---

## Key Entities

* **Mantine Theme (`src/theme.ts`):** 10-shade `brand-pink` and `sidebar-violet` color arrays, typography scales, `md` default radius, card defaults, and breakpoints (`sm: 768px`, `lg: 1200px`).
* **AppLayout (`src/layouts/AppLayout.tsx`):** Root layout container with top header, responsive navigation sidebar, mobile burger toggle, and main content area.
* **PageHeader (`src/components/PageHeader/`):** Unified header displaying page titles in Playfair Display serif, optional subtitles, breadcrumb navigation, and primary action slot.
* **StatusBadge (`src/components/StatusBadge/`):** Semantic status indicator mapping standard lifecycle statuses (`active`, `inactive`, `pending`, `blocked`, `warning`, `success`) to Mantine colors in light variant.
* **DataTable (`src/components/DataTable/`):** Responsive server-driven data grid supporting search, column sorting, row multi-selection, row action menus, CSV export trigger, loading overlay, pagination summary, tablet column hiding (`hideOnTablet`), and mobile fallback (`ListCard` mode).
* **StatCard (`src/components/StatCard/`):** KPI summary card rendering metric values, uppercase labels, optional icons, and color-coded percentage trends (`delta`).
* **FilterChipGroup (`src/components/FilterChipGroup/`):** Multi- or single-select filter chip selector styled in brand pink.
* **StatePlaceholder (`src/components/StatePlaceholder/`):** Standardized empty, loading, and error states with Tabler icons, message copy, and retry/action button slots.

## API Endpoints

This is a frontend foundational module and does not define new backend API routes. It consumes authentication status:

* `GET /backoffice/auth/me`
  * Fetch authenticated user session and role.
  * Authentication Required: Yes (Bearer token)

* `POST /backoffice/auth/login`
  * Authenticate administrator/user credentials and receive session token.
  * Authentication Required: No

## Main Workflows

### 1. Application Initialization & Theme Injection
1. Browser loads `index.html` with Google Fonts CDN links.
2. Root `main.tsx` imports `@mantine/core/styles.css` and mounts `<MantineProvider theme={theme}>`.
3. `index.css` applies `var(--mantine-font-family)` and sets canvas background color (`#f7f7f2`).

### 2. Standard Page Layout Flow
1. Page component mounts inside `<AppLayout>`.
2. Page renders `<PageHeader title="..." breadcrumbs={[...]} action={<Button />} />`.
3. Page arranges metrics using `<StatCard>` components.
4. Page presents record listings through `<DataTable columns={...} data={...} />`.

### 3. Responsive DataGrid Flow
1. Desktop (`≥ 1200px`): Full table renders all columns, selection checkboxes, and sort buttons.
2. Tablet (`768px – 1199px`): Columns marked `hideOnTablet: true` are hidden to prevent horizontal blowout.
3. Mobile (`< 768px`): `DataTable` automatically switches from HTML `<table>` to a stack of `<Card>` components displaying primary title, secondary field rows, and top-right actions menu.

## Security Considerations

* Session tokens (`bloom-backoffice-token`) are retrieved from `localStorage` and sent via standard `Authorization: Bearer <token>` headers.
* Navigation and actions in `AppLayout` and `DataTable` support future role-based permission checks before rendering privileged buttons or routes.

---

## Important Business Rules

* `theme.ts` is the single source of truth for color tokens, typography, and breakpoints.
* No hardcoded fonts or ad-hoc colors inside component files; all styling must use Mantine theme variables (`brand-pink`, `sidebar-violet`, `headings.fontFamily`).
* Mobile breakpoint for table-to-card transformation is aligned to `theme.breakpoints.sm` (`768px`).
