# Module: Foundation & Design System (FE-SH-00-01 & FE-SH-00-02) - Version 2

## Module Overview

This module establishes the comprehensive design system foundation, Mantine v8 theme configuration, root responsive AppShell layout, and complete suite of standardized UI components for the She Bloom backoffice web application. It serves as the single source of truth for design tokens, typography, palettes, icons, feedback overlays, and layout structures for all operational roles (Admin, Moderator, Mentor).

---

## Module Responsibilities

* Configure the centralized Mantine v8 theme (`src/theme.ts`) with custom 10-shade palettes (`pink`, `violet`, `gray`, `green`, `yellow`, `red`, `blue`).
* Inject semantic tokens and fonts into CSS `:root` via Mantine `cssVariablesResolver` to enforce strict zero hardcoded hex and font styling.
* Provide centralized icon abstraction (`<AppIcon />`) wrapping 70+ Figma outline icons with standard stroke (1.5).
* Provide root application shell (`AppLayout.tsx`) utilizing Mantine's `alt` layout, violet sidebar, tablet compact mode (72px), mobile burger drawer, search bar, language switcher, notification badge, and role switcher.
* Provide modular badges: `<StatusBadge />` (with leading dot), `<RoleBadge />` (`ADMIN`, `MODERATORE`, `MENTOR`), `<PhaseBadge />` (`FASE 1`, `FASE 2`), and `<CounterBadge />`.
* Provide data visualization and navigation components: `<DataTable />` (responsive sorting, filtering, selection, CSV export, tablet column hiding, and mobile card transformation), `<StatCard />`, `<ContentCard />`, `<ListCard />`, `<AgendaSlot />`, and `<FilterChipGroup />`.
* Provide feedback, overlay, and state components: `<Alert />`, `<ToastNotification />` (floating dark pill), `<ActionModal />` (icon circle dialogs), `<DrawerWrapper />` (slide-out panel with sticky footer), and `<StatePlaceholder />` (EmptyState, loading, and error states).

* **StatusBadge (`src/components/StatusBadge/`):** Status indicator with colored leading dot for entity lifecycle states.
* **RoleBadge (`src/components/RoleBadge/`):** Role badge for `ADMIN`, `MODERATORE`, and `MENTOR`.
* **PhaseBadge (`src/components/PhaseBadge/`):** Mentorship workflow phase indicator (`FASE 1`, `FASE 2`).
* **CounterBadge (`src/components/CounterBadge/`):** Compact circular count badge.
* **AppAvatar (`src/components/AppAvatar/`):** User avatar supporting image URLs, initials fallback, and status dot indicators.
* **DataTable (`src/components/DataTable/`):** Server-driven responsive data table with search, export CSV, row actions, mobile card fallback, and pagination stats.
* **StatCard (`src/components/StatCard/`):** Metric display with KPI values, uppercase labels, and delta percentage trends.
* **ContentCard (`src/components/ContentCard/`):** Structured card with header action slots and clean content padding.
* **ListCard (`src/components/ListCard/`):** Horizontal list item with avatar, title, subtitle, badge, and trailing action.
* **AgendaSlot (`src/components/AgendaSlot/`):** Agenda/session card with accent border, date/time chips, and client metadata.
* **FilterChipGroup (`src/components/FilterChipGroup/`):** Grouped chip filters for faceted list views.
* **ToastNotification (`src/components/ToastNotification/`):** Dark pill notification with icon, message, and close button.
* **ActionModal (`src/components/ActionModal/`):** Modal dialog with top icon circle, headline in Playfair Display, and action button configurations.
* **DrawerWrapper (`src/components/DrawerWrapper/`):** Slide-over drawer with title, close button, scrollable body, and sticky footer action buttons.
* **StatePlaceholder (`src/components/StatePlaceholder/`):** Standardized empty, loading, and error state view with circular icon container and CTA buttons.
* **PageHeader (`src/components/PageHeader/`):** Page header with breadcrumbs, Playfair Display title, subtitle, and action buttons.

## Main Workflows

### 1. Theme and Token Injection
1. Application mounts `<MantineProvider theme={theme} cssVariablesResolver={cssVariablesResolver}>`.
2. Mantine generates CSS custom properties on `:root` (`--bg-canvas`, `--bg-sidebar`, `--brand-primary`, `--font-family-heading`, etc.).
3. Global styles in `index.css` apply tokens without hardcoded values.

### 2. Standard Responsive Screen Navigation Flow
1. Page view renders inside `<AppLayout>`.
2. Header renders global search, language toggle (`IT`/`EN`), notification bell with unread badge, and user avatar.
3. Sidebar dynamically switches between expanded (desktop 260px), compact icon with tooltip (tablet 72px), or overlay drawer (mobile < 768px).
4. Page view displays `<PageHeader />` with breadcrumb navigation and action triggers.

### 3. Responsive DataGrid & Overlay Flow
1. Desktop renders multi-column `<DataTable />` with sorting and selection.
2. Tablet hides non-critical columns (`hideOnTablet: true`).
3. Mobile automatically transforms tabular rows into interactive cards.
4. User clicks an action to trigger `<ActionModal />` or `<DrawerWrapper />` with standardized buttons.
5. Action completion triggers a floating `<ToastNotification />`.

## Security Considerations

* Zero raw HTML injections; all component text and inputs are sanitized via React and Mantine primitives.
* Privileged actions in `AppLayout` and `DataTable` support role-based permission gating (`UserRole: 'admin' | 'moderator' | 'mentor'`).
* Authorization tokens are automatically attached via Axios interceptors in `src/api/client.ts`.

---

## Important Business Rules

* **Strict Zero Hardcoding Rule:** No hardcoded hex color codes or font family strings anywhere in component code. All styles must consume theme CSS variables (`var(--...)`) or Mantine color tokens.
* **Component Centralization:** Direct imports of external icon libraries (e.g., `@tabler/icons-react`) outside of `src/components/AppIcon/AppIcon.tsx` are forbidden.
* **Language Standards:** English is the default UI language during active development; Italian localization strings will be activated in subsequent localization phases.
* **Responsive Breakpoints:**
  * Desktop: `≥ 992px` (Full 260px sidebar)
  * Tablet: `768px – 991px` (Compact 72px sidebar)
  * Mobile: `< 768px` (Drawer navigation & card view table transformation)
