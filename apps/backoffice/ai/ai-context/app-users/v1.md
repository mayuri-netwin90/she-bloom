# Module: App Users (Backoffice)

## Module Overview

The **App Users** module provides the administrative backoffice interface to view, filter, inspect, and manage She Bloom registered mobile app users and Bloom Club subscribers (Requirements: `RF-BO-USR-01`).

---

## Module Responsibilities

* Display total registered mobile users and Bloom Club subscribers count.
* Provide quick status filtering (`All`, `Bloom Club`, `Free`, `Blocked`).
* Search app users across name and email in real-time.
* Table view with column sorting (`User`, `Subscription`, `Registered on`, `Sessions`, `Status`) and multiple row selection.
* Mobile-responsive fallback to card list layout with navigation carats.
* View and edit user details in a slide-out `DrawerWrapper`.
* Block/unblock or suspend user confirmation via `ActionModal`.
* Export app users list via CSV.

---

## Key Entities

* **AppUserItem**:
  * `id`: string (UUID)
  * `name`: string
  * `email`: string
  * `subscription`: `'club' | 'free'`
  * `registeredOn`: string (formatted date `DD/MM/YYYY`)
  * `sessions`: number
  * `status`: `'active' | 'blocked' | 'to_verify' | 'anonymized'`

## UI Components & Design Parity

* **PageHeader**:
  * Title: `"App users"` (font: `var(--font-family-heading)`)
  * Breadcrumbs: `Management / App users`
  * Subtitle: `12,480 registered users · 1,936 Bloom Club subscribers`
  * Action: `Export CSV` button (outline pink, download icon)
* **Search & Filter Bar**:
  * Left: Search input (`placeholder="Search by name or email"`) + Pill segment control (`All`, `Bloom Club` / `Club`, `Free`, `Blocked`)
  * Right: `More filters` button (Desktop view)
* **Data Presentation**:
  * Desktop (>= 992px) & Tablet (768px - 991px): Standardized Mantine table with zebra striping, row selection checkboxes, avatar initials, subscription pill badge (`CLUB` / `FREE`), registered date, session count, and `StatusBadge` (`ACTIVE`, `BLOCKED`, `TO VERIFY`, `ANONYMIZED`). Inline actions: View (`eye`), Edit (`edit`), and More (`dots`).
  * Mobile (< 768px): Card stack with user avatar, name, email, subscription type, status badge, and drill-down chevron (`chevronRight`).
* **Pagination Bar**:
  * Result summary: `"1–8 of 248 results"`
  * Page controls: Mantine `Pagination` with `color="sidebar-violet"` and dark violet active state.
* **Drawer & Modal**:
  * `DrawerWrapper` showing full user details and edit form.
  * `ActionModal` for blocking / unblocking users.
